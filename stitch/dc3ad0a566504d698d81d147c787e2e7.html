React Öğrenme Notları

calendar_today 12 Ekim 2023 • 8 dakika okuma

Modern web geliştirme dünyasının en popüler kütüphanesi olan React ile ilgili temel kavramları ve ileri seviye mimari yaklaşımları burada topluyorum. Bu notlar sürekli güncellenmektedir.

Neden React?

React, kullanıcı arayüzleri oluşturmak için kullanılan deklaratif, verimli ve esnek bir JavaScript kütüphanesidir. Bileşen tabanlı mimarisi sayesinde karmaşık arayüzleri yönetilebilir parçalara böler.

  • Virtual DOM: Gerçek DOM yerine sanal bir kopya üzerinden çalışarak performansı artırır.
  • Tek Yönlü Veri Akışı: Veri yönetimi daha öngörülebilir hale gelir.
  • JSX: HTML benzeri bir sözdizimi ile JavaScript içinde UI tanımlama kolaylığı sağlar.
  • Geniş Ekosistem: Hooks, Context API ve zengin kütüphane desteği.

Temel Bir Bileşen Yapısı

Aşağıdaki örnekte basit bir Counter bileşeninin useState hook'u ile nasıl oluşturulduğunu görebilirsiniz:

import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div class="p-4 bg-surface-container-low rounded-xl">
      <p>Şu anki değer: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        Artır
      </button>
    </div>
  );
}

export default Counter;

Hooks Kullanımı Hakkında Önemli Notlar

Hooks kullanırken dikkat edilmesi gereken en önemli kural, onları sadece en üst seviyede çağırmaktır. Döngüler, koşullar veya iç içe fonksiyonlar içinde hook çağırmamalısınız. Bu, React'in state durumunu doğru sırayla takip edebilmesi için kritiktir.

Gelecek bölümlerde useEffect ile yan etkilerin yönetimi ve useContext ile global state yönetimi konularına değineceğim.
