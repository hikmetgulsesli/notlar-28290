## 1. Genel Bakış Notlar uygulaması, kullanıcıların markdown formatında notlar oluşturmasına, düzenlemesine, etiketlemesine ve aramasına olanak tanıyan modern bir web uygulamasıdır. Uygulama tamamen tarayıcıda çalışır ve veriler localStorage üzerinde saklanır — sunucu gerektirmez. Türkçe arayüzlü, hızlı ve erişilebilir bir deneyim sunmayı hedefler. Hedef kitle: Günlük notlarını düzenli tutmak isteyen profesyoneller, öğrenciler ve içerik üreticileri. Markdown desteği sayesinde teknik dokümantasyon yazmak isteyen geliştiriciler de uygulamayı kullanabilir. ## 2. Hedefler - Kullanıcılar markdown formatında not yazabilmeli ve anlık önizleme görebilmeli - Notları etiketlerle kategorize edebilmeli ve etiketlere göre filtreleyebilmeli - Başlık ve içerik bazlı tam metin arama yapabilmeli - Notları tarihe göre sıralayabilmeli (en yeni/en eski) - localStorage ile kalıcı veri saklama — sayfa yenilense bile veri korunmalı - Boş, düzenleme ve arama sonuç yok durumları için kullanıcı dostu feedback - Tüm interactive elementlerde klavye navigasyonu - Responsive tasarım: mobil 320px — desktop 1920px+ ## 3. Tech Stack Detayı - **Framework:** React 18.3 - **Build:** Vite 5.x - **Styling:** Tailwind CSS 3.4 - **State:** useState + useReducer (yerel state, localStorage senkronizasyonu) - **Storage:** localStorage API (veri kalıcılığı için) - **Routing:** React Router DOM 6.x (SPA içi navigasyon) - **Markdown:** react-markdown + remark-gfm (parsing ve render) - **Icons:** Lucide React (emoji yok, sadece SVG icon) - **ID Generation:** crypto.randomUUID() (not ve etiket ID'leri için) - **Language:** TypeScript 5.x ## 4. Fonksiyonel Gereksinimler ### 4.1 Not Oluşturma - Başlık (zorunlu, max 100 karakter) - İçerik (zorunlu, markdown formatında, sınırsız uzunluk) - Etiketler (opsiyonel, virgülle ayrılmış string, max 10 etiket) - Oluşturulma tarihi: otomatik, ISO 8601 formatında - Güncellenme tarihi: otomatik, her düzenlemede güncellenir - Hata: "Başlık boş bırakılamaz" — başlık girilmeden kaydet butonu pasif - Başarı: Notlar listesine dön, yeni not listede en üstte görünür ### 4.2 Not Düzenleme - Mevcut notun tüm alanları düzenlenebilir - Güncelleme tarihi otomatik yenilenir - Değişiklikler localStorage'a anında kaydedilir - "Geri al" desteği yok — kullanıcı dikkatli olmalı ### 4.3 Not Silme - Her not kartında silme butonu (sağ üst köşede) - Tıklama sonrası onay modalı açılır: "Bu notu silmek istediğinizden emin misiniz? Bu işlem geri alınamaz." - Onay butonu: "Sil", iptal butonu: "İptal" - Başarılı silme sonrası: kullanıcı notlar listesine yönlendirilir, toast mesajı görünür ### 4.4 Not Listeleme - Tüm notlar kartlar halinde listelenir - Her kart: başlık, etiketler (chip olarak), güncellenme tarihi, önizleme (içeriğin ilk 150 karakteri) - Sıralama: tarihe göre azalan (en yeni üstte) — varsayılan - Sayfa başında "Yeni Not" butonu ### 4.5 Arama - Üst bar'da arama inputu - Başlık VE içerik bazlı arama (case-insensitive) - Her kelime yazıldığında filtrele (debounce yok, anlık) - Arama boşken: tüm notlar gösterilir - Sonuç yokken: "Sonuç bulunamadı" mesajı ve arama kutusuna odaklanılır ### 4.6 Etiketleme ve Filtreleme - Her nota en fazla 10 etiket eklenebilir - Etiketler virgül veya enter ile ayrılır - Etiket inputu: "Etiketler (virgülle ayırın)" placeholder - Sol sidebar'da tüm kullanılan etiketler listesi - Etikete tıklayınca o etikete sahip notlar filtrelenir - Aktif filtre: seçili etiket vurgulu, "Filtreyi temizle" butonu görünür ### 4.7 Markdown Editör - Split view: sol tarafta editor (textarea), sağ tarafta canlı preview - Editor: monospace font, syntax highlighting yok (plain markdown yazımı) - Preview: render edilmiş markdown — başlıklar, listeler, linkler, kod blokları - Tab tuşu: editor'de 2 space ekler (default browser davranışı engellenir) ### 4.8 Empty States - İlk açılış (henüz not yok): "Henüz notunuz yok. İlk notunuzu oluşturun!" + büyük "Yeni Not" butonu - Arama sonuç yok: "Sonuç bulunamadı" altında "Aramayı temizle" linki - Etiket filtresi sonucu yok: "Bu etikete sahip not bulunamadı" ## 5. Veri Modeli ### Note Entity ```typescript interface Note { id: string; // crypto.randomUUID() title: string; // max 100 chars content: string; // markdown string tags: string[]; // max 10 items createdAt: string; // ISO 8601 updatedAt: string; // ISO 8601 } ``` ### localStorage Schema ``` Key: "notlar-28290-notes" Value: Note[] (JSON stringifiy) ``` ### Tag Entity (derived, computed) ```typescript interface TagCount { name: string; count: number; } ``` ## 6. Non-Functional Requirements ### 7.1 Performans - İlk yükleme (boş cache): < 1.5 saniye - Arama filtreleme: < 50ms - Not kaydetme: < 100ms - Bundle size hedefi: < 150KB (gzip, critical JS) ### 7.2 Erişilebilirlik (WCAG 2.1 AA) - Klavye navigasyonu: Tab/Shift+Tab ile tüm elementlere erişim - Enter/Space ile buton ve link aktivasyonu - Screen reader: ARIA labels, role attributes, live regions (arama sonuçları) - Kontrast: tüm metinler 4.5:1 ve üzeri - Focus visible: tüm interactive elementlerde 2px outline - Touch hedefleri: minimum 44x44px ### 7.3 Tarayıcı Desteği - Chrome 90+, Firefox 88+, Safari 14+, Edge 90+ - iOS Safari 14+, Android Chrome 90+ - Responsive: 320px (mobile) — 1920px (desktop) - localStorage desteği zorunlu ## 8.
