Project Phoenix: Next Generation Architecture

ARCHIVE Updated: Oct 12, 2023

The goal of Project Phoenix is to rebuild our core infrastructure using a serverless-first approach, prioritizing global latency and developer experience. By shifting away from monolith services, we enable independent scaling for our high-traffic ingestion endpoints.

// Proposed scaling strategy
const scalingPolicy = new AutoScaler({
  min: 2,
  max: 100,
  strategy: 'proactive'
});

We are currently evaluating the performance impact of the new edge middleware. Initial benchmarks suggest a 40% reduction in Time to First Byte (TTFB) across APAC regions.

Regional Distribution

The rollout will begin with us-east-1 and eu-central-1 clusters by Q4.
